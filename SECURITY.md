# Security policy

## Supported versions

filmstrip is pre-1.0.0. Fixes land in the latest release only.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's vulnerability reporting](https://github.com/jordond/filmstrip/security/advisories/new).

Include the filmstrip version, the target and backend, and the smallest file or edit that shows the problem. A media
file that crashes or hangs a decode is worth reporting, even when the fault turns out to be in the platform's decoder
or in ffmpeg.

You should hear back within a week. Once a fix is released the advisory is published, with credit unless you'd
rather not be named.
