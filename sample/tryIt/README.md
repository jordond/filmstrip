# tryIt

The small app behind the Try it TV on the site's landing page. It loads the beach sunset clip and runs one edit on it,
with trim, grade and title steps the reader turns on and off, and can export the result.

The landing page frames it from `/demo/try/` once the reader presses LOAD. The keys, the notes and the export button
all live on the page. The app only draws the picture, so run on its own it plays the clip with no steps on.

## The protocol

Page and app talk over `postMessage`, one JSON string per message, between two windows on the same origin.

- The page sends controls: `steps` with `trim`, `grade` and `title`, then `export`, `save`, `cancel` and `retry`.
- The app sends `ready` once it has drawn, and a `status` whenever its position, trim, export or errors change.
- The app's `index.html` sends `failed` if the wasm can't start.

Either side ignores a message it doesn't know. The app's end is `TryProtocol.kt` and `TryBridge.kt`. The page's end is
`website/src/lib/tryProtocol.ts`.

`protocol.fixture.json` holds examples of every message, and both sides test against it. `TryProtocolFixtureTest`
gets it as a constant generated by `generateProtocolFixture`, and `tryProtocol.test.ts` reads the file. A change to
the protocol changes the fixture, the Kotlin side and the TypeScript side together, so both tests stay green.

## What it uses

`sample/common` for the clip (`SamplePreset`), the export download and the design tokens, which brings in
`filmstrip`, plus `filmstrip-compose` for the player. The module also has a JVM target so the engine tests run
without a browser.

## Running it

```sh
./gradlew :sample:tryIt:wasmJsBrowserDevelopmentRun
```

Then open <http://localhost:8080> in a Chromium-based browser. To drive it from the real page, build it with
`./gradlew :sample:tryIt:wasmJsBrowserDistribution` along with the webApp distribution, then run `bun run assemble` and
`bun run preview` in `website/`. The docs workflow builds the same distribution, and `website/scripts/assemble.sh`
copies `build/dist/wasmJs/productionExecutable` into the site as `/demo/try`.

## Tests

```sh
./gradlew :sample:tryIt:jvmTest
./gradlew :sample:tryIt:wasmJsBrowserTest
```

`jvmTest` covers the engine and checks the landing page's code snippet still matches the edit the app runs.
`wasmJsBrowserTest` runs the protocol fixture test and the preset loader's abort test in headless Chrome. The page's
half runs with `bun test` in `website/`.
