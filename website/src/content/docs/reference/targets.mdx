filmstrip builds for these Kotlin targets.

| Platform | Kotlin targets                  |
| -------- | ------------------------------- |
| Android  | The Android library target      |
| iOS      | `iosArm64`, `iosSimulatorArm64` |
| macOS    | `macosArm64`                    |
| JVM      | `jvm`                           |
| Browser  | `js`, `wasmJs`                  |

Apple targets are arm64 only, so native builds don't run on an Intel Mac, and neither does the iOS simulator there.

The versions each platform needs are on [Requirements](/start/requirements/).

The Compose modules have no native macOS target, so a native macOS app can export and preview but can't use the Compose
player or timeline. A Compose Desktop app runs on the `jvm` target with the ffmpeg backend instead.
