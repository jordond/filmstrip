## Browsers

filmstrip is tested on {TESTED_BROWSERS}. Firefox and Safari have WebCodecs too, but nobody has tested filmstrip
on them yet. They may work.

## ffmpeg

The JVM backend links no ffmpeg and bundles none. It runs `ffmpeg` and `ffprobe` as separate programs, found
through `FfmpegConfig`, then the `FILMSTRIP_FFMPEG` and `FILMSTRIP_FFPROBE` environment variables, then `PATH`. An
older build, or a git build with no release number, is reported as `FilmstripError.ToolchainMissing` when you plan
or export, never as a crash.
