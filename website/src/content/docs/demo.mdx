This is the filmstrip sample app, built for the browser with Kotlin/Wasm and Compose Multiplatform
{versions.composeMultiplatform}. It plays, edits and exports the sample clips with the WebCodecs backend, all inside
this page. Nothing is uploaded anywhere. For more room, open it <a href={DEMO_HOST}>full screen</a>.

<DemoFrame />

:::note
The demo needs WebCodecs and WebAssembly garbage collection. It's tested on {TESTED_BROWSERS}. Other browsers may
work but aren't tested.
:::
