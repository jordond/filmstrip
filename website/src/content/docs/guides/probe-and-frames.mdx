## Probe

`probe` reads a source's metadata without decoding it. An unreadable file comes back as a `Failure`, so there's nothing
to catch.

<Snippet file="commonMain/kotlin/dev/jordond/filmstrip/docs/guides/ProbeAndFrames.kt" region="probe" />

`MediaInfo` has the `duration`, a `video` and an `audio` track, either of which is null when the source has none, and
`isExportable`, which is false for DRM-protected files. Those can't be exported or previewed, so check it first.

For an MP4 or QuickTime file, `duration` is the length its movie header gives, which counts only what each track's
edit list presents. An AAC track that opens on an encoder delay doesn't run long by that delay, and every platform
reports the same length for the same file. Any other container gets the length the platform reads.

On a video track, size a target from `displaySize`, which has rotation and pixel aspect applied, rather than `codedSize`.
`bitDepth` is often null, since only HEVC carries it somewhere every backend can read. `hdrTransfer` is null for SDR.

Android and Apple read a container with core alone. The JVM and the browser need their backend artifact. Without it, both
fail with `BackendMissing`, naming the artifact to add. A still needs no backend on any target.

On the JVM a probe that `ffprobe` hasn't finished within its deadline is stopped and refused as `TimedOut`, which names
the read and its deadline, rather than leaving the call hanging. See [Limits](/reference/limits/#probe-deadline).

## Capabilities

`capabilities` asks what this device's encoders can do. The answer is cached per process. On the JVM a test encode
that runs past its deadline fails the call naming the encoder, and that failure isn't cached, so asking again measures
again.

<Snippet file="commonMain/kotlin/dev/jordond/filmstrip/docs/guides/ProbeAndFrames.kt" region="capabilities" />

`encoderFor` answers one codec's limits, such as `maxSize`, `maxFrameRate` and `maxBitrate`, or null when there's no
encoder for it. To find out what will happen to one particular edit, use [`plan`](/guides/export/#plan), which already
takes all of this into account.

## One frame

`frame` renders the frame covering an instant of a composition, with its effects applied. You own the image and have to
close it.

<Snippet file="commonMain/kotlin/dev/jordond/filmstrip/docs/guides/ProbeAndFrames.kt" region="frame" />

Leave `heightPx` null to render at the composition's own output height. A height at or above that height renders at that
height too, since a frame is never scaled up. Zero or less fails with `InvalidComposition`.

For one source with no edit, pass the source directly.

<Snippet file="commonMain/kotlin/dev/jordond/filmstrip/docs/guides/ProbeAndFrames.kt" region="frame-source" />

## Many frames

`frames` emits one result per position, each as it's ready. It's made for a timeline strip, so a frame may come from the
nearest sync sample rather than the one covering its position. `presentationTime` says where each one actually landed.
Use `frame` when a position has to be exact.
